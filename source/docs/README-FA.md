# راهنمای فارسی Lumen — Revision 9 (بسته‌ی سورس)

Lumen پخش‌کننده‌ی رسانه‌ی ویندوزی با رابط شیشه‌ای، انیمیشن‌ها و تعاملات وب است؛ رابط با HTML/CSS/JavaScript ساخته شده و Electron آن را به برنامه‌ی دسکتاپ تبدیل می‌کند.

> **این ZIP فقط سورس است؛ هیچ EXE، نصاب یا خروجی build داخل آن نیست.** برای ساخت ویندوز، پوشه‌ی `source` را Extract کنید و در ویندوز فایل `build-windows-r9.bat` را اجرا کنید. خروجی build بیرون از پوشه‌ی سورس ساخته می‌شود.

در R8 تشخیص زیرنویس کناری برای نام‌های فارسی/Unicode، فایل‌های هم‌پوشه با نام متفاوت، پوشه‌های شلوغ و زیرپوشه‌های متعارف `Subs` تقویت شد. Preview نمونه از Settings حذف شد، اما تنظیمات ظاهری و دکمه‌ی **Reset look** حفظ شدند. R9 خطای `CRYPT_E_REVOCATION_OFFLINE` در دانلود Windows را با retry کنترل‌شده حل می‌کند: پس از شکست curl معمولی، curl با `--ssl-no-revoke` دوباره تلاش می‌کند و SHA-256 ثابت آرشیو همچنان پیش از استخراج اجباری است؛ این fallback برای FFmpeg و Electron اعمال شده است.

## ساخت، نصب و اجرا

پس از ساخت محلی با BAT، نصاب `Lumen-Setup-1.0.0-r9.exe` داخل پوشه‌ی خروجی `build\r9\windows` قرار می‌گیرد. نصب برای حساب فعلی ویندوز است و دسترسی Administrator نمی‌خواهد. میانبر Start Menu ساخته می‌شود؛ میانبر Desktop در حالت عادی خاموش است.

```bat
Lumen-Setup-1.0.0-r9.exe
Lumen-Setup-1.0.0-r9.exe /desktop
Lumen-Setup-1.0.0-r9.exe /PORTABLE /D=D:\Apps\Lumen
```

پارامتر `/desktop` میانبر Desktop را روشن می‌کند. `/PORTABLE` فقط فایل‌ها را استخراج می‌کند و هیچ میانبری نمی‌سازد. Start Menu در نصب معمول همیشه ساخته می‌شود.

برای بازکردن رسانه، فایل/پوشه را روی پنجره رها کنید یا از منوی Open استفاده کنید:

```bat
Lumen.exe "D:\Movies\film.mkv"
Lumen.exe "D:\Series"
```

## پشتیبانی رسانه و کدک

نسخه‌ی ویندوزی R9، **FFmpeg 9.0.2 و ffprobe را همراه برنامه** نصب می‌کند. بنابراین برای مسیر عادی نصب، هیچ codec pack یا برنامه‌ی خارجی لازم نیست. موتور همراه طیف وسیعی از ظرف‌ها و کدک‌ها را می‌خواند؛ از جمله MKV، MP4/MOV، WebM، AVI، MPEG-TS، FLV، VOB، WMV/ASF، Ogg و MXF؛ تصویر HEVC/H.265 (از جمله x265 ده‌بیتی)، H.264، AV1، VP9/VP8، MPEG-1/2/4، VC-1، ProRes و WMV؛ صدا AAC، MP3، FLAC، Opus/Vorbis، AC-3/E-AC-3، DTS، TrueHD، WMA، ALAC و PCM.

مرورگر داخلی همه‌ی این کدک‌ها را مستقیم پخش نمی‌کند. Lumen با ffprobe فایل را بررسی می‌کند و هرجایی که لازم باشد تصویر/صدا را هنگام پخش به H.264/AAC تبدیل می‌کند؛ این به‌ویژه مشکل تصویر سیاه در HEVC/x265 را برطرف می‌کند. تبدیل فایل‌های 4K یا نرخ‌بیت بالا می‌تواند CPU زیادی مصرف کند. فایل رمزگذاری‌شده، خراب، ناقص یا دارای پروفایل نامعمول ممکن است همچنان پخش نشود.

در تنظیمات → **Media engine & codecs** وضعیت موتور همراه دیده می‌شود. انتخاب یک نسخه‌ی سفارشی FFmpeg فقط گزینه‌ی پیشرفته و اختیاری است. برنامه در زمان اجرا چیزی دانلود یا نصب نمی‌کند.

## URL / Stream و کلیپ‌بورد

از منو **Open URL / stream…** را بزنید یا کلید U را فشار دهید. متن فعلی کلیپ‌بورد به‌طور خودکار داخل ورودی قرار می‌گیرد و انتخاب می‌شود. لینک مستقیم، HLS (`.m3u8`) و بعضی streamها قابل استفاده‌اند.

روی ورودی لینک راست‌کلیک کنید تا منوی **Cut / Copy / Paste** باز شود. Cut و Copy به انتخاب متن نیاز دارند؛ Paste در محل نشانگر یا جای متن انتخاب‌شده درج می‌شود.

## میانبرهای تازه‌ی صفحه‌کلید

| کلید | کار |
| --- | --- |
| `PageDown` | رفتن به ویدیوی بعدی (در انتهای فهرست به اول برمی‌گردد) |
| `PageUp` | رفتن به ویدیوی قبلی |
| `Delete` | فایل در حال پخش به **Recycle Bin** منتقل می‌شود و همان لحظه ویدیوی بعدی پخش می‌شود |

`Delete` فایل را به سبد بازیافت ویندوز می‌فرستد؛ یعنی پاک‌سازی قابل بازگردانی است، نه حذف قطعی. اگر فقط یک آیتم در فهرست پخش باشد، Lumen فایل را حذف نمی‌کند و پیام هشدار نشان می‌دهد تا فایلِ در حال پخش به‌طور تصادفی از بین نرود. پس از حذف، فایل از فهرست پخش، موقعیت ادامه‌ی پخش و فهرست زیرنویس‌های به‌خاطرمانده هم پاک می‌شود.

میان‌برهای قبلی (Space، ←/→، `M`، `F`، `W`، `V`، `B`، `P`، `I` و …) بدون تغییر باقی مانده‌اند؛ فهرست کامل با `F1` نمایش داده می‌شود.

## سبک‌سازی و سرعت

- **موتور FFmpeg دوباره وصل شد:** متد `transcode_start` در فهرست مجاز `preload.js` جا افتاده بود؛ نتیجه این بود که مسیر تبدیل برای فایل‌های ناسازگار (HEVC/x265، 10-bit، MKV با کدک غیرمرورگری و …) در عمل هیچ کاری نمی‌کرد و پیام «Cannot start the built-in media conversion» می‌داد. اکنون این مسیر کامل کار می‌کند.
- **فهرست پخش سبک شد:** بازسازی کامل DOM در هر play/pause، هر افزودن فایل و هر به‌روزرسانی عنوان حذف شد؛ رسم فهرست حداکثر یک‌بار در هر فریم انجام می‌شود، با امضای محتوا کش می‌شود، جست‌وجوی اندیس از O(n²) به O(n) رسیده و موقعیت اسکرول حفظ می‌شود. افزودن یک پوشه با صدها ویدیو دیگر ثانیه‌ها طول نمی‌کشد.
- **بدون ffprobe برای هر فایل:** فهرست ذخیره‌شده هنگام شروع دیگر برای تک‌تک آیتم‌ها توکن/ffprobe نمی‌گیرد؛ بررسی فقط برای فایلی انجام می‌شود که واقعاً باز می‌شود.
- **لایه‌های شیشه‌ای نامرئی دیگر رندر نمی‌شوند:** پنل‌های بسته، OSD صدا، نشانگر زوم، منوی راست‌کلیک، مودال و دکمه‌ی بزرگ پخش با `visibility:hidden` از درخت رندر خارج می‌شوند؛ پیش‌تر هرکدام یک بلور backdrop زنده روی ویدیو نگه می‌داشتند.
- **انیمیشن‌های بیدلیل متوقف شدند:** اسپینر مخفی و نوار اکولایزر فهرست دیگر مدام فریم مصرف نمی‌کنند؛ اکولایزر با `scaleY` (روی GPU) حرکت می‌کند.
- **حالت کم‌مصرف واقعی شد:** گزینه‌ی *Low-resource mode* در Settings حالا همه‌ی بلورهای زنده را خاموش و سطوح را توپر می‌کند؛ برای لپ‌تاپ‌های ضعیف یا نمایشگر 4K گزینه‌ی مناسبی است.
- **استارت سبک‌تر:** تصویر پس‌زمینه‌ی دوم فقط هنگام نمایش دانلود/دیکود می‌شود، فایل بلااستفاده‌ی `scene_bright.jpg` حذف شد، نوشتن همگام `config.json` در هر تغییر تنظیمات (مثلاً هنگام کشیدن اسلایدر صدا) برداشته شد، و کش متادیتای میزبان/ffmpeg محدود شد تا حافظه با پوشه‌های بزرگ رشد نکند. فایل‌های استاتیک هم ETag/304 دارند.
- **رفع باگ‌های کوچک:** کلیدهای جهت‌دار و PageDown در منوهای کشویی (`select`) دیگر پخش را کنترل نمی‌کنند؛ فهرست پخش برای استریم‌های داخل فهرست هم اندیس درست را نگه می‌دارد و next/prev خراب نمی‌شود؛ کنترل‌های رسانه‌ی ویندوز (Media Session) دکمه‌های بعدی/قبلی و جلو/عقب بردن دارند.

## اطلاعات مجوز FFmpeg

نسخه‌ی همراه از بایگانی Gyan.dev، FFmpeg 9.0.2 essentials، استفاده می‌کند. README آن build را GPLv3 معرفی می‌کند و commit سورس FFmpeg را `946fcce07b` می‌داند. فایل مجوز و README همراه برنامه در `resources/ffmpeg/` است؛ نسخه‌ی متنی Notice هم در `vendor/ffmpeg/win-x64/NOTICE-FA.txt` قرار دارد.

**مهم:** فهرست وابستگی‌های build شامل کتابخانه‌های بیرونی نیز هست. وجود لینک commit FFmpeg به‌تنهایی اثبات نمی‌کند که سورس Corresponding Source و اسکریپت ساخت تمام وابستگی‌ها موجود است. پیش از انتشار عمومی، این مورد باید جداگانه تکمیل و بررسی شود.

## راهنمای توسعه

برای ساخت نسخه‌ی ویندوز به Node.js 22.12 یا جدیدتر و runtime رسمی Electron 44.5.1 برای Windows x64 نیاز است. **نه `unzip` لازم است و نه 7-Zip**: فایل `tools/zipfs.js` هر دو بایگانی پین‌شده را به‌ترتیب با `unzip`، 7-Zip، یک بازکنندهٔ داخلی (فقط با `zlib` که همراه Node است) و در آخر PowerShell باز می‌کند؛ ویندوزِ خالی هم بیلد می‌شود. **NSIS اختیاری است**: فقط برای ساختن فایل نصاب (`Lumen-Setup`) لازم است و خود برنامه هیچ نیازی به آن ندارد. اگر NSIS نبود، بیلد با موفقیت تمام می‌شود، نسخه‌ی پرتابل ساخته می‌شود و `Lumen-portable-1.0.0-r9.zip` هم برای اشتراک‌گذاری ساخته می‌شود. اسکریپت‌های `build-windows-r9.bat` و `tools/build-installer.js` خودشان NSIS را در `PATH`، متغیر `NSIS_DIR`، مسیرهای معمول (Chocolatey، Scoop، پوشه‌ی لینک‌های `winget`) و کلید رجیستری نصاب رسمی می‌گردند؛ برای نصب: `winget install --id NSIS.NSIS -e` یا `choco install nsis -y` یا نسخه‌ی رسمی از nsis.sourceforge.io (به‌همراه افزودن پوشه به `PATH`). فایل `build-windows-r9.bat` دریافت/تأیید runtimeها و ساخت را انجام می‌دهد؛ اگر بررسی معمول TLS به‌خاطر دسترسی‌نداشتن به سرویس revocation شکست بخورد، دانلود را با گزینه‌ی `--ssl-no-revoke` تکرار می‌کند؛ chain/hostname validation و بررسی SHA-256 حفظ می‌شوند. جزئیات هر مرحله در کنسول است. اگر به‌جای BAT دستی build می‌کنید، ابتدا بایگانی FFmpeg را در زمان ساخت دریافت و تأیید کنید؛ برنامه‌ی نصب‌شده هیچ‌چیز را دانلود نمی‌کند:

```bash
npm install
node tools/prepare-ffmpeg.js --download
node tools/build-windows.js --zip .electron/electron-v44.5.1-win32-x64.zip
node tools/build-installer.js --revision r9
```

برای توضیح تغییرات R7، اصلاحات R8 و وصله‌ی دانلود R9 و آزمون‌های انجام‌شده: [`BUGFIXES-FA.md`](BUGFIXES-FA.md).
